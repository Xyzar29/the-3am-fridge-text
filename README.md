## The line

> 3am. The freezer and I took a vote: you're not hungry, you're bored. Motion carried. Go to bed.

One line, 95 characters. A smart fridge that has been awake all night
finally speaks: it held a vote with the freezer, and the verdict is that
its owner is not hungry — just bored. No milk, no ice, no door left open.

## How it works

`main.ts` (Node 22) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`) and enforces the competition gate itself:
1–140 characters, a single line, more than whitespace.

```sh
node main.ts
```
